## Schedule integration

Run `scripts/preview-web.sh [port]` with the macOS Swift toolchain and Python 3.9 or newer. It builds `TipoffCheck` and listens on loopback (port 8765 by default). The frontend is `web/index.html`, `web/guide.css`, and `web/guide.js`. The preview server also serves `web/portfolio-preview.html` as a stand-in for the portfolio link. The guide uses Roboto for body text and controls, with Barlow Condensed for display headings and times. Team logos use ESPN’s image CDN and MLB’s logo host. Selected network marks use ESPN and Wikimedia-hosted assets, including the [Peacock wordmark](https://commons.wikimedia.org/wiki/File:NBCUniversal_Peacock_Logo_(2026).svg), [FOX wordmark](https://commons.wikimedia.org/wiki/File:FOX_wordmark-black.svg), and [Prime Video mark](https://commons.wikimedia.org/wiki/File:Prime_Video_logo_(2024).svg). Additional marks include [TNT](https://commons.wikimedia.org/wiki/File:TNT_Logo_2016.svg), [HBO Max](https://commons.wikimedia.org/wiki/File:HBO_Max_May_2025_(Horizontal).svg), [truTV](https://commons.wikimedia.org/wiki/File:TruTV_2014.svg), and [Altitude](https://en.wikipedia.org/wiki/File:Altitude_Sports_logo.svg). Both Altitude and the NHL feed’s ALT label use the Altitude mark. Distinct marks now cover [Altitude 2 / ALT2](https://www.tvpassport.com/tv-listings/stations/altitude-2/5864), [Altitude+](https://www.altitudeplus.com/) (the official site’s desktop logo), and [NBA TV](https://en.wikipedia.org/wiki/File:NBA_TV.svg). Altitude 2 uses TV Passport’s transparent PNG and renders white; Altitude+ keeps its official white mark, and NBA TV retains its original colors. Accessible names and text fallback preserve each service identity. These four marks render white for the dark background. Loaded broadcaster logos use proportional boxes based on natural image dimensions, with a shared 0.5 rem gap between networks, regional labels, and team-logo/name pairs. The national network column remains a fixed width for away-logo alignment. Loaded broadcaster logos replace the visible names. The names remain available to assistive technology and display as text until a logo loads or when a logo is unavailable. Regional and radio labels follow the feed categories. The LP badge applies only to a separately listed League Pass entry.

The local `GET /tip-off/schedule?sport=nba&day=YYYY-MM-DD&zone=America%2FDenver` endpoint invokes `TipoffCheck --web <sport> <day> <zone> <cache-directory>`. It returns `{snapshot, saved}` with ISO 8601 dates and a null or absent snapshot when listings are unavailable. It reuses the native source and display logic. The preview cache is under `.build/web-cache`, with a five-minute freshness window and a separate Altitude cache.

Production uses Apache and PHP 8.1. Apache routes the schedule request to `web/schedule.php`, deployed as `api/tipoff-schedule.php`. PHP validates request parameters and calls `api/schedule-runtime.php`. It invokes the Linux build of `TipoffCheck --web-cached` with a five-second process limit, returning fresh or saved schedules without network waits. Saved responses preserve their original freshness and use Saved listings labels. Stale/missing caches trigger detached `--web` refreshes with an 85-second process limit, isolated locks for sport/date/time zone, and a 30-second retry backoff. Missing data returns HTTP 202 while a refresh is active; the browser polls with an eight-second per-request timeout and a 95-second overall bound. Available followed games render immediately. Completed background results are read on the next date visit or Today action. The executable and its writable schedule cache are outside the web root. The preview server remains available for local development.

Build the production executable from this repository in the official `swift:6.3-jammy` image for `linux/amd64` with `swift build -c release --static-swift-stdlib --product TipoffCheck`, then strip the release executable. Verify its shared dependencies with `ldd` and run it as the web user against live feeds before exposing the routes. Keep the cache across executable replacements and web release rollbacks.
