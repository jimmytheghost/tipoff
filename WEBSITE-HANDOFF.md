## Schedule integration

Run `scripts/preview-web.sh [port]` with the macOS Swift toolchain and Python 3.9 or newer. It builds `TipoffCheck` and listens on loopback (port 8765 by default). The frontend is `web/index.html`, `web/guide.css`, and `web/guide.js`. The preview server also serves `web/portfolio-preview.html` as a stand-in for the portfolio link. The guide uses Roboto for body text and controls, with Barlow Condensed for display headings and times. Team logos use ESPN’s image CDN and MLB’s logo host. Selected network marks use ESPN and Wikimedia-hosted assets, including the [Peacock wordmark](https://commons.wikimedia.org/wiki/File:NBCUniversal_Peacock_Logo_(2026).svg), [FOX wordmark](https://commons.wikimedia.org/wiki/File:FOX_wordmark-black.svg), and [Prime Video mark](https://commons.wikimedia.org/wiki/File:Prime_Video_logo_(2024).svg). Additional marks include [TNT](https://commons.wikimedia.org/wiki/File:TNT_Logo_2016.svg), [HBO Max](https://commons.wikimedia.org/wiki/File:HBO_Max_May_2025_(Horizontal).svg), [truTV](https://commons.wikimedia.org/wiki/File:TruTV_2014.svg), and [Altitude](https://en.wikipedia.org/wiki/File:Altitude_Sports_logo.svg). Both Altitude and the NHL feed’s ALT label use the Altitude mark; Altitude 2 and Altitude+ retain their distinct text labels. These four marks render white for the dark background. Loaded broadcaster logos replace the visible names. The names remain available to assistive technology and display as text until a logo loads or when a logo is unavailable. Regional and radio labels follow the feed categories. The LP badge applies only to a separately listed League Pass entry.

The local `GET /tip-off/schedule?sport=nba&day=YYYY-MM-DD&zone=America%2FDenver` endpoint invokes `TipoffCheck --web <sport> <day> <zone> <cache-directory>`. It returns `{snapshot, saved}` with ISO 8601 dates and a null or absent snapshot when listings are unavailable. It reuses the native source and display logic. The preview cache is under `.build/web-cache`, with a five-minute freshness window and a separate Altitude cache.

Production uses Apache and PHP 8.1. Apache routes the schedule request to `web/schedule.php`, deployed as `api/tipoff-schedule.php`. PHP validates request parameters and invokes the Linux build of `TipoffCheck` with a per-sport refresh lock and a process timeout. The executable and its writable schedule cache are outside the web root. The preview server remains available for local development.

Build the production executable from this repository in the official `swift:6.3-jammy` image for `linux/amd64` with `swift build -c release --static-swift-stdlib --product TipoffCheck`, then strip the release executable. Verify its shared dependencies with `ldd` and run it as the web user against live feeds before exposing the routes. Keep the cache across executable replacements and web release rollbacks.

- NBA.com with ESPN fallback for NBA, ESPN for NFL and WNBA, and the respective league feed with ESPN fallback for NHL and MLB. Carry the Nuggets Altitude supplement only with agreement on date, opponent, home/away, and tipoff. Keep regional footnotes and original freshness on saved results.
- Keep saved schedules separate by sport, local date, and time zone. Preserve each sport’s working snapshot through upstream errors or malformed data. Show per-sport source, timestamp, fallback or saved state, and unavailable state as applicable. Only display “No games scheduled” after a valid empty result for the selected day. One league failure should leave other leagues usable.
- Preserve native display ordering, including national NBA listings first and Nuggets priority within each group, plus Broncos, Avalanche, and Rockies priority in their respective sports. Use calendar days across time-zone boundaries and daylight saving transitions. Persist only schedule and broadcaster fields. Exclude scores, standings, and live telemetry, and avoid inferring streaming eligibility or local rights.
