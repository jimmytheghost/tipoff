# Tipoff

Tipoff is a personal NBA, NFL, WNBA, NHL, and MLB viewing guide for macOS, Windows, and the browser. See the [README](README.md) for implemented features and installation.

The browser guide is live at [JimmyWeber.com/tipoff](https://www.jimmyweber.com/tipoff) and remains available for local preview. [Website handoff](WEBSITE-HANDOFF.md) tracks routes, mobile behavior, data requirements, and integration evidence. The [expanded Tipoff portfolio page](https://www.jimmyweber.com/pages/projects/tipoff/) covers macOS, Windows, and the browser guide. Its source materials are in the [portfolio content package](docs/portfolio/HANDOFF.md).
