# Tipoff

Tipoff is a personal NBA, NFL, WNBA, NHL, and MLB viewing guide with native macOS and Windows apps. See the [README](README.md) for implemented features and installation.

The browser guide is live at [JimmyWeber.com/tipoff](https://www.jimmyweber.com/tipoff) and remains available for local preview. [Website handoff](WEBSITE-HANDOFF.md) tracks routes, mobile behavior, data requirements, and integration evidence. The [portfolio content package](docs/portfolio/HANDOFF.md) prepares an expanded portfolio entry with macOS, Windows, and browser sections; that page expansion has not been integrated or published.
