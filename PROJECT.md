# Tipoff

Tipoff is a personal NBA, NFL, WNBA, NHL, and MLB viewing guide with native macOS and Windows apps. See the [README](README.md) for implemented features and installation.

The browser guide is available for local preview and intended for hosting on JimmyWeber.com for checking which sports have games and where those games are listed while away from a computer. [Website handoff](WEBSITE-HANDOFF.md) tracks the proposed routes, mobile behavior, data requirements, and integration checks.
